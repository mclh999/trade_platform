王伟锋报告的范围与仓库 [`database/`](../../../database/) 目录一致：

- `book`：书籍发布记录；
- `book_order`：由组内下单模块负责人设计，不在本人报告中展开。

王伟锋报告对应的建表 SQL 见 [`sql/04_book_publish.sql`](../../../sql/04_book_publish.sql)；许文博报告对应的建表 SQL 见 [`sql/`](../../../sql/) 下的 `01`～`03`。
