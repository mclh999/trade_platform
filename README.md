# 校园二手书交易平台

> 面向校园用户的二手书流转平台，覆盖书籍发布、检索与查看、下单预留和订单取消。

**仓库**：`trade_platform`　·　**课程**：软件工程导论实验　·　**当前阶段**：需求分析

---

## 项目简介

校园二手书交易平台用于整理和流转校园内的闲置图书。平台围绕书籍信息发布、查询浏览和预留订单建立核心业务流程，为后续数据库设计与软件实现提供需求依据。

## 核心业务

| 业务模块 | 主要功能 |
| --- | --- |
| 书籍发布 | 发布书籍信息；一条发布记录对应一本实体书。 |
| 检索与查看 | 按书籍信息检索，并查看书籍详情和当前状态。 |
| 订单管理：下单 | 买家为可售书籍提交预留请求；系统在处理请求时核验书籍状态。 |
| 订单取消 | 买家取消自己的有效预留后，书籍恢复可售，订单历史保留。 |

> **业务边界**：下单表示预留，不包含支付、退款、物流或交易完成流程。当前需求规则以小组评审后的共享版本为准。
